# Final run figures and compact data

This directory contains the publication-facing products reconstructed from the
checksum-verified final delivery:

- `training-curves.svg` and `training-curve-binned.csv`: training telemetry;
- `validation-curve.csv`: validation loss across checkpoints;
- `inference-sweep.svg` and `inference-sweep.csv`: CFG/NFE selection;
- `milestone-progression.png`: fixed-seed milestone samples;
- `human-study-sample-grid.png`: deterministic, non-curated final samples;
- `memorization-distributions.svg`: CLIP/DINO nearest-neighbor diagnostics;
- `summary.json`: hashes and compact final metrics.

See [`../../FINAL_REPORT.md`](../../FINAL_REPORT.md) for interpretation and
limitations. These figures are evidence artifacts, not cherry-picked showcase
samples; the visually curated gallery is in [`../../assets/showcase`](../../assets/showcase/README.md).
